#### 3.1.2 漏洞摘要

Zimbra 官方安全通告与 HKCERT 公告披露了 ZCS `10.1.20` 修复的多个安全漏洞，其中 3 个新分配 CVE 均由 Rapid7 研究员 Jonah Burgess 报告，均为已认证用户场景下的授权与访问控制缺陷：

- **`CVE-2026-10631`（EWS 扩展访问控制）：** Zimbra EWS（Exchange Web Services）扩展存在访问控制缺陷，可能导致用户越权访问或执行受限的邮件数据操作；
- **`CVE-2026-50054`（邮箱委派授权）：** 邮箱委派（mailbox delegation）功能授权校验不严，被委派方可能获取超出其授权范围的访问能力；
- **`CVE-2026-50055`（邮件转发限制绕过）：** 管理员启用邮件转发限制后，已认证用户仍可绕过限制将邮件外发至限制外地址，造成邮件数据外泄。

上述 3 个漏洞的详细技术原理厂商未公开（Rapid7 报告未发布，NVD/CVE.org 无记录），CVSS 均标注 TBD；HKCERT 将通告整体评为"高度风险"，主要驱动因素为同通告中**正在被广泛利用**的 `CVE-2026-73570`（SNMP 通知组件 OS 命令注入，无需认证，已于 08-23 期完整收录分析）。由于 `10.1.20` 修复版本自 2026-07-20 发布至今已逾一个月，部署单位应优先确认自身版本并完成升级。

#### 3.1.11 风险影响

漏洞成功利用后，可能导致：

- 已认证用户越权访问他人邮件数据（EWS 访问控制缺陷、邮箱委派授权问题）；

#### 3.1.13 修复与缓解措施

#### 官方修复

1. 将 Zimbra Collaboration Suite 升级至 `10.1.20` 或更高版本（`yum update` / `apt update`，或按官方升级文档操作）；
2. 升级前完成配置、邮件数据与系统备份；
3. 在测试环境验证兼容性及回退方案后，再于生产环境升级；
4. 升级后核验版本（`zmcontrol -v`）、服务状态及业务运行情况；
5. 重新执行漏洞检测（版本核查、配置核查）并留存修复证据。

#### 临时缓解

无法立即升级时，可采取：

- 审计并收紧 EWS 扩展访问控制、邮箱委派授权与邮件转发限制配置；
- 暂停/禁用不必要开启的邮件转发、委派或 EWS 功能；
- `CVE-2026-73570`：禁用 `snmp_notify`、卸载 `zimbra-snmp` 套件并收敛服务暴露面（详见 08-23 期 3.1.13）；
- 限制 Zimbra 管理控制台（7071）与邮件服务的互联网暴露（防火墙/ACL 仅允许可信来源）；
- 启用多因素认证与最小权限策略，加强邮件系统日志审计与异常外发监控。

#### 3.2.2 漏洞摘要

本批 12 个 CVE 均为 Google Chrome 151.0.7922.169 稳定版更新（2026-08-18）修复的 Chromium 引擎安全缺陷，Microsoft Edge 151.0.4129.101（2026-08-20）同步整合修复，HKCERT 于 08-24 发布 Edge 通告（中度风险）。缺陷分布在 WebGL、V8 JavaScript 引擎、Skia 图形库、Media、USB、GPU、CORS、CredentialProvider、Browser 等组件，以内存安全类问题为主（缓冲区溢出、释放后使用、类型混淆），另有信息泄露、不当实现与条件竞争。

所有漏洞的共通利用条件为**诱导用户访问恶意网页**（用户交互），无在野利用标注、无公开 PoC，Chrome/Edge 均通过自动更新机制推送修复。NVD CVSS 最高为 `CVE-2026-76035`（**9.6**，Media 组件，macOS，作用域变更），Google 官方将 `CVE-2026-76034`（WebGL 缓冲区溢出）评为 **Critical**（其余为 High）。

**技术原理：**

本批漏洞根因集中在浏览器处理不可信 Web 内容时的内存安全缺陷：V8 引擎的类型混淆与计算错误、WebGL 的缓冲区溢出与释放后使用、Skia 的信息泄露、USB/GPU 组件的条件竞争与未初始化资源使用等。攻击者构造恶意网页，当用户使用受影响版本浏览器访问时，渲染/执行引擎在处理恶意数据过程中触发越界读写、类型混淆或悬垂指针访问，进而可能实现沙箱内任意代码执行、信息泄露或浏览器崩溃（拒绝服务）。

**核心利用链：**

```text
攻击者
  └─ 构造恶意网页/链接（含恶意 WebGL、V8 载荷等）
      └─ 诱导用户使用受影响浏览器访问
          └─ 渲染引擎处理恶意内容触发内存安全缺陷
              └─ 越界读写 / 类型混淆 / UAF
                  └─ 沙箱内代码执行 / 信息泄露 / 崩溃（DoS）
```

## 五、当日处置建议

1. **优先处置（P1）— Zimbra 多漏洞（含在野利用的 `CVE-2026-73570`）：** 所有 Zimbra 部署单位立即核查版本（`zmcontrol -v`）并升级至 `10.1.20+`（该版本 2026-07-20 已发布）；`CVE-2026-73570` 的 CISA KEV 处置截止（2026-08-24）已过，须确认升级与取证分诊已完成；同步审计 EWS 扩展、邮箱委派与邮件转发限制配置，排查异常转发/委派变更与 73570 相关入侵痕迹（详见 3.1.9）。
2. **批量升级（P2）— Edge/Chrome 151 批次 12 个 CVE：** Edge 升级至 `151.0.4129.101+`、Chrome 升级至 `151.0.7922.169+`；企业通过终端管理平台批量推送并核验版本覆盖率；提醒用户勿访问不可信站点与不明链接。
3. **威胁情报关注 — 网银木马与钓鱼工具包：** 关注 ToxicPanda/Manic 网银木马与 iAuthFlow v2 钓鱼工具包（passkey 劫持）动向，金融业务加强会话异常检测与风控联动，企业监控异常 passkey 注册并推广钓鱼抗性 MFA。
4. **恶意诱饵与位置隐私：** 提醒用户勿下载 GTA VI 等游戏"泄露/破解"文件；评估 Find My 等位置共享服务的信任模型风险，谨慎共享位置。
5. **OT/关键基础设施：** 关注斯洛伐克测速摄像头风险警告与发电厂攻击事件跟进，联网设备（摄像头、工控设备）纳入资产管理、网络隔离与固件更新。
6. **常规要求：** 对疑似遭受攻击的系统保留日志、流量、进程、文件及内存证据；完成修复后进行复测，并更新资产台账和漏洞处置记录。
