## 三、漏洞详情

### 3.1 CVE-2026-117532 — REDAXO Structure/History 临时登录令牌伪造

!!! danger "严重漏洞（CVSS 9.3）"
    未认证攻击者可伪造临时登录令牌，可能接管后台会话。

#### 3.1.1 基本信息

| 字段 | 内容 |
| --- | --- |
| **CVE编号** | `CVE-2026-117532` |
| **风险等级 / CVSS** | 严重 / 9.3（CVSS 4.0） |
| **影响版本 / 修复版本** | REDAXO 5.3.0 至 5.21.4 之前 / 5.21.4 |
| **披露日期** | 2026-10-27 |
| **KEV / PoC** | 快照未标记 / 快照未标记 |

#### 3.1.2 检测与处置

- 确认 REDAXO 版本并将后台限制到 VPN 或受信网段；升级至 5.21.4 或更高版本。
- 升级后使现有后台会话和临时令牌失效，审计管理员新增、异常登录与令牌使用记录。
- 参考：[REDAXO 安全公告](https://github.com/redaxo/core/security/advisories/GHSA-px8f-whj8-hrpq)。

### 3.2 CVE-2026-116870 — Octopus Server OIDC issuer 校验不一致

!!! warning "高危漏洞（CVSS 8.7）"
    对 OIDC token issuer 的验证不一致，可能使不应信任的身份令牌跨越认证边界。

#### 3.2.1 检测与处置

- 核查 OIDC issuer、受众与签名验证配置，回溯认证失败和管理员权限变化事件。
- 按 [Octopus SA2026-15](https://advisories.octopus.com/post/2026/sa2026-15) 升级；禁止宽松 issuer 匹配及跨环境身份提供方复用。

### 3.3 CVE-2026-116872 — Semantic MediaWiki 查询规范化资源耗尽

!!! warning "高危漏洞（CVSS 8.7）"
    `TermParser::normalize_compact_form()` 的算法复杂度问题可由未认证请求触发，耗尽解析工作进程 CPU。

#### 3.3.1 检测与处置

- 对公开 Wiki 的查询/API 限制请求体、执行时间和速率，排查异常长查询与 CPU 峰值。
- 升级至 7.3.1，并同步评估同日披露的其余 21 条 Semantic MediaWiki 漏洞。
- 参考：[修复提交](https://github.com/SemanticMediaWiki/SemanticMediaWiki/commit/c2bf1699dec4016e21ce52613152bda799ce87d4)、[安全公告](https://github.com/SemanticMediaWiki/SemanticMediaWiki/security/advisories/GHSA-j2r2-7qpg-p675)。

### 3.4 CVE-2026-117540 — svg-sanitizer 二次复杂度 CPU 耗尽

!!! warning "高危漏洞（CVSS 8.7）"
    重叠 PHP 标签可使 SVG 清洗逻辑反复扫描输入，造成工作进程 CPU 耗尽。

#### 3.4.1 检测与处置

- 限制 SVG 上传大小、并发和处理超时，并隔离上传转换进程。
- 升级至 1.1.0；同时评估 `CVE-2026-117539`（远程引用绕过）和 `CVE-2026-117541`（异常拒绝服务）。
- 参考：[修复提交](https://github.com/darylldoyle/svg-sanitizer/commit/9ba9001493f5da737759303f13bd965ebdaa778c)、[安全公告](https://github.com/darylldoyle/svg-sanitizer/security/advisories/GHSA-2v7c-jx29-jprp)。
