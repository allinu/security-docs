### 3.1 CVE-2026-63077 — JetBrains TeamCity agent 轮询协议反序列化未认证远程代码执行漏洞

!!! danger "严重漏洞"

#### 3.1.2 漏洞摘要

TeamCity 的构建代理（agent）通过轮询协议（agent polling protocol，相关端点包括 `/app/agents/protocols` 及遗留 XML-RPC 端点）从 TeamCity 服务器拉取构建任务。该漏洞存在于 agent 轮询协议的数据处理过程中：服务器对轮询请求中携带的不可信数据进行反序列化时缺乏充分的信任边界校验（CWE-502），攻击者无需任何身份认证，仅需构造特制的轮询请求即可**绕过认证检查**，并利用反序列化在 TeamCity 服务进程上下文中执行任意操作系统命令。

该漏洞于 2026-07-10 由安全研究员 Antoni Tremblay 依据协调披露机制私下报告给 JetBrains，2026-07-27 官方公开披露并发布修复版本。**所有 TeamCity On-Premises 版本均受影响**；TeamCity Cloud（云端托管）实例已由厂商完成修复，不受影响。2026-08-05，美国 CISA 将该漏洞收录进已知被利用漏洞目录（KEV），确认其存在在野利用，并要求按 BOD 26-04 于 2026-08-08 前完成修复。

#### 3.1.3 影响产品与版本

| 厂商 | 产品/组件 | 受影响版本 | 修复版本 | 部署形态 |
|---|---|---|---|---|
| JetBrains | TeamCity On-Premises（服务器，agent 轮询协议） | 全部 On-Premises 版本（2026.1.3 之前、2025.11.7 之前） | `2025.11.7` / `2026.1.3`；无法升级者可安装官方安全补丁插件（支持 2017.1+） | 本地/自建服务器 |
| JetBrains | TeamCity Cloud | 不受影响（厂商已修复） | 无需操作 | 云服务 |

!!! warning "版本说明"
    版本范围以 JetBrains 官方安全公告为准（[TeamCity 官方博客公告](https://blog.jetbrains.com/teamcity/2026/07/cve-2026-63077/)）。修复版本为 2025.11.7 或 2026.1.3；安全补丁插件仅修复本漏洞（CVE-2026-63077），官方仍建议完整升级。

#### 3.1.5 利用条件与技术原理

| 条件 | 状态 | 说明 |
| --- | --- | --- |
| 网络可达 | 是 | 需 HTTP(S) 可达 TeamCity 服务器（默认 Web 端口 8111，agent 轮询协议端点） |
| 身份认证 | 无需 | 未认证攻击者即可触发（NVD 向量 PR:N） |
| 用户交互 | 不需要 | 无需受害者交互 |
| 特定配置 | 否 | 默认配置即受影响 |
| 利用复杂度 | 低 | NVD 向量 AC:L |

**技术原理：**

TeamCity agent 与服务器之间的轮询协议涉及对请求/响应数据的反序列化处理。当服务器解析 agent 轮询请求时，未对其中携带的序列化数据实施有效的信任边界校验（如类过滤/白名单），攻击者可将恶意构造的序列化对象嵌入轮询请求，触发 Java 反序列化 gadget 链，从而在服务端进程中执行任意代码。由于攻击面位于未认证可达的 HTTP 端点，且无需任何前置权限，漏洞被评为 CVSS 9.8（严重）。

**核心利用链：**

```text
攻击者
  └─ 通过 HTTP(S) 访问暴露的 TeamCity 服务器（默认 8111）
      └─ 构造携带恶意序列化对象的 agent 轮询请求（/app/agents/protocols 等端点）
          └─ 服务器反序列化不可信数据（CWE-502）
              └─ 绕过认证检查，触发 gadget 链
                  └─ 以 TeamCity 服务进程权限执行任意操作系统命令
```

#### 3.1.11 风险影响

漏洞成功利用后，可能导致：

- 未认证远程在 TeamCity 服务器上执行任意操作系统命令；
- 获取 TeamCity 服务进程权限，接管 CI/CD 构建系统；
- 窃取构建凭据、源代码、制品仓库密钥及部署密钥；
- 篡改构建流程与产物，向软件供应链投毒；
- 以 TeamCity 服务器为跳板横向移动至内网其他系统；
- 被勒索软件组织利用（TeamCity 为勒索攻击高价值目标，2024 年 CVE-2024-23917 曾被勒索软件利用）。

#### 3.1.13 修复与缓解措施

#### 官方修复

1. 将 TeamCity On-Premises 升级至 `2025.11.7` 或 `2026.1.3` 及以上版本（可下载安装包或使用 TeamCity 自动更新）；
2. 无法立即升级的，安装官方[安全补丁插件](https://www.jetbrains.com/privacy-security/issues-fixed/)（支持 TeamCity 2017.1+；2024.03+ 版本可在 Administration | Updates 的 Available security updates 中查看并应用；2017.1–2018.1 安装后需重启服务器）；
3. 升级前完成配置、构建历史与数据的备份；
4. 在测试环境验证兼容性及回退方案；
5. 升级后核验版本（2025.11.7 / 2026.1.3）、补丁插件状态及构建流水线运行情况；
6. 对曾暴露于互联网且未及时修复的实例，按失陷假设开展取证排查。

#### 临时缓解

无法立即升级时，可采取：

- 限制 TeamCity Web 端口（默认 8111）及 agent 轮询端点的互联网访问，仅允许可信构建网络访问；
- 通过防火墙、ACL、安全组仅允许可信 IP 访问 TeamCity 服务；
- 在 WAF 或网关增加针对 agent 轮询协议端点异常请求的拦截规则；
- 加强 TeamCity 服务账号与服务器操作系统日志审计、主机监控和异常外联检测；
- 对高风险实例实施网络隔离或访问收敛，优先于业务可用性保障安全。

## 五、当日处置建议

1. **TeamCity 升级（P0，2026-08-08 前完成）**：立即核查全部 TeamCity On-Premises 实例版本，低于 2025.11.7 / 2026.1.3 的一律升级或安装官方安全补丁插件（2017.1+）；对照 [JetBrains 公告](https://blog.jetbrains.com/teamcity/2026/07/cve-2026-63077/)与 [CISA KEV](https://www.cisa.gov/known-exploited-vulnerabilities-catalog?field_cve=CVE-2026-63077) 执行 BOD 26-04 时限管理。
2. **TeamCity 暴露面收敛**：限制 8111 等管理端口及 agent 轮询端点（`/app/agents/protocols`、XML-RPC）的互联网暴露，仅允许可信构建网络访问；对曾暴露的实例按失陷假设开展日志与主机取证排查（异常进程、异常文件、异常外联）。
3. 对互联网暴露的 CI/CD、VPN、网关、安全设备、中间件和管理平台开展资产排查，确认无其他受影响组件暴露。
4. 云平台与 SaaS 账号全面启用 MFA、最小权限与访问审计，防范凭据窃取型攻击（参考 Snowflake 案）。
5. 对疑似遭受攻击的系统保留日志、流量、进程、文件及内存证据，并开展 WebShell、恶意进程、异常账号及横向移动排查。
6. 完成修复后进行复测，并更新资产台账和漏洞处置记录；本报告唯一漏洞已有官方补丁，无"暂无补丁"项。
