## 其他情报

### 安全事件

- **朝鲜"蓝宝石雪"（Sapphire Sleet）操控 npm 供应链：axios 等四款库沦陷** — [安全圈报道](https://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652078127&idx=3&sn=d19e98b1f7dd0926263b1ea3ef9675e1)称朝鲜黑客组织"蓝宝石雪"操控 npm 包供应链，Axios 等四款库沦陷。公开渠道信息核实：Amazon（AWS）安全团队公开将 **typo-crypto、debug、chalk、axios** 四个被投毒的 npm 包归因于同一朝鲜背景组织 Sapphire Sleet（微软追踪代号），归因置信度为中等，依据为共享的 C2 基础设施与 TTP（trojanized NPM 包、post-install 钩子、代码复用）。其中 axios 事件中，攻击者利用一名主要维护者泄露的 npm 账号凭据，绕过项目正常的 GitHub Actions CI/CD 流程发布恶意版本（axios@1.14.1 / axios@0.30.4）；chalk 与 debug 的劫持事件分别在被发现约 16 个月与 10 个月后才完成归因。[The Register](https://www.theregister.com/cyber-crime/2026/07/30/amazon-links-four-poisoned-npm-packages-to-one-north-korean-crew/5281120) | [The Stack](https://www.thestack.technology/amazon-north-korea-npm-attacks/) | [The Hacker News](https://thehackernews.com/2026/07/amazon-links-debug-and-chalk-npm-hijack.html) | [SC Media](https://www.scworld.com/news/amazon-attributes-axios-debug-chalk-npm-attacks-to-dprks-sapphire-sleet)。该组织长期从事加密货币盗窃、虚假招聘与针对开发者的社工攻击。**修复/排查建议**：检查项目锁文件与依赖树中是否出现上述库的非官方版本，审查 CI/CD 与 npm 发布凭据（启用 2FA 与 OAuth/粒度令牌），对存量依赖执行完整性校验。

- **黑客洗劫硬件钱包，比特币被盗** — [安全圈报道](https://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652078127&idx=1&sn=d40089d99cce7a93151959806aa70d6d)：黑客洗劫硬件钱包导致比特币被盗。同期公开报道显示，Galaxy Research 通过链上溯源披露多波针对硬件钱包的攻击，相关冷钱包固件缺陷事件累计损失已超 1 亿美元（如 Coldcard 相关事件，参考[银河研究报道](https://rao.cash/cn/cryptonews/1335-bitcoin-theft-via-coldcard-losses-exceed-100-million-according-to-galaxy.html)与[公开分析](https://post.smzdm.com/p/a3mopn05/)）。**建议**：仅从官方渠道购买并升级硬件钱包固件，验证设备固件签名，大额资产分地址存放，警惕供应链与仿冒设备。

### 安全动态与情报

- **Chrome 近 3 个版本修复 1442 个漏洞** — [安全圈报道](https://mp.weixin.qq.com/s?__biz=MzIzMzE4NDU1OQ==&mid=2652078127&idx=2&sn=6ae0e3468281094b71a924e772335be6)：谷歌近期 Chrome 安全更新披露，**149.x、150.x、151.x 三个主要版本共修复 1442 个安全漏洞**，超过此前 23 个主要版本修复总数（[安恒威胁情报中心](https://ti.dbappsecurity.com.cn/security-info/bulletin?id=15817)）。修复阶段据称采用多代理协作辅助漏洞修复，显著提升了修复效率（参考[相关分析](https://jandan.net/p/123446/)）。**建议**：及时升级 Chrome/Chromium 内核浏览器至最新稳定版，企业侧跟进对应 WebView 与浏览器组件版本。

- **朝鲜杀毒软件 SiliVaccine（청류벽）技术架构曝光** — [黑鸟](https://mp.weixin.qq.com/s?__biz=MzAxOTM1MDQ1NA==&mid=2451187955&idx=1&sn=549f457d1820169a705195a5bdbff4d0)分析 2026 年最新版 SiliVaccine：已删除全部趋势科技盗版代码，转向双开源引擎架构 —— 基础查杀基于 ClamAV，行为检测搭载开源恶意软件聚类工具 Malheur，右键扫描菜单直接命名为「ClamShell-Malheur」。内置 ClamAV 特征库版本较旧，自动更新模块默认关闭（可设每 2 小时在线更新）。该变化被视为朝鲜网络自研能力升级的体现，也侧面反映其安全软件供应链逐步脱离盗版商业代码。
