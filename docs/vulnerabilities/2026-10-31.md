#### 3.1.2 漏洞摘要

SOCFortress CoPilot focuses 存在 **路径遍历** 类型缺陷。NVD 给出的 CVSS 评分为 **10.0**（3.1，向量 `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H`），即 远程可达、无需认证、无需用户交互、复杂度低。 归类为 `CWE-22`、`CWE-73`、`CWE-434`。 受影响版本范围按描述为 `< 0.1.77`。 该条目暂无 EPSS 评分，通常因披露时间过近而尚未纳入评分数据集。 Nuclei、Metasploit、Exploit-DB 与 GitHub 四源检索均未发现公开利用代码。 厂商公告尚未明确修复版本，需关注后续更新。

> 原文摘要（NVD）：SOCFortress CoPilot focuses on providing a single pane of glass for all your security operations needs. Prior to 0.1.77, `POST /api/scoutsuite/generate-gcp-report` in `backend/app/integrations/scoutsuite/routes/scoutsuite.py` admits admin and analyst users and validates the uploaded content as `GCPScoutSuiteJSON`, but passes raw `file.filename` from the multipart header to `save_file_to_directory` in `backend/app/integrations/scoutsuite/services/scoutsuite.py`. The writer combines this filename with `scoutsuite-report` using `os.path.join` without sanitization or a resolved-path containment check. A traversal filename therefore writes the supplied JSON outside the intended report directory.
