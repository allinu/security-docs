### 1.3 今日重点关注

1. **`CVE-2026-88779`：Citrix NetScaler ADC / Gateway 内存缓冲区越界（已在野利用）**  
   攻击者可通过网络触发内存越界，导致进程崩溃或潜在代码执行。当前状态为 **已被 CISA 于 2026-10-04 纳入 KEV、确认在野利用**，建议 **立即升级至各分支安全版本（14.1-73.41 / 13.1-64.28 等）并收敛管理接口暴露面**。

2. **`CVE-2026-105207` / `105209` / `105215` / `105211`：ZITADEL 身份平台认证绕过与账号接管集群**  
   外部 IdP 绑定未验主因子（9.8）、跨组织 passkey 注册接管（9.6）、伪造外部 IdP 回调“预劫持”账号（9.1）、Login V2 经 returnCode 泄露 OTP（8.1）——**任一编号均可在仅知晓受害者登录名的前提下实现账号接管**。建议 **立即升级至 3.4.15 / 4.17.3（及各分支对应修复版）**。

3. **`CVE-2026-105134` / `CVE-2026-105135`：两例 CVSS 3.1 = 10.0 的未认证远程代码注入**  
   Ahsay AhsayCBS 复制接收器 `UpdateReceivers.do` 的 `random` 参数 OS 命令注入（升级 10.3.4）与 InternLM MindSearch Planner Agent 代码注入（厂商未响应、暂无补丁），均为 **无需认证、可远程利用、利用已被公开** 的高危项。

4. **`CVE-2026-103355`：WordPress Unlimited Elements for Elementor 未认证盲 SQL 注入（本期唯一公开 PoC）**  
   影响 ≤ 2.0.20，渲染路径即触发，**未认证攻击者可通过布尔差分确认 SQL 执行**；修复版 2.0.21 加入 `validateIDsList()` 白名单。GitHub 已出现只读验证型 PoC 仓库。

5. **跨期 KEV 到期提醒：`CVE-2026-102489`/`102490`（Zammad）整改期限为 2026-10-05（当日）**，`CVE-2026-104286`（FortiMail）已逾期 1 天，`CVE-2026-88779`（NetScaler）剩余 2 天，请优先闭环。

### 1.4 综合研判

本期窗口 NVD 新收录 60 条有效漏洞，数量较上期进一步回落（约 -57%），但**风险高度集中、单点危害突出**：11 条严重漏洞中，**身份认证基础设施类占比最高**（ZITADEL 一家贡献 4 条严重的认证绕过/授权缺陷），其余严重项分布在**未认证 RCE/命令注入**（AhsayCBS、MindSearch）、**安全远程访问网关**（首个在野利用项 NetScaler 为高危）、**开源组件证书校验缺失**（go-micro、gopay）与**面向公众的 Web 应用**（Elementor 插件、AVideo）。本窗口 CISA KEV **新增 1 条**（`CVE-2026-88779`，Citrix NetScaler，累计 1734 条），**这是本期唯一确认在野利用的条目**，也是本期风险最高的一条。公开 PoC 生态**整体无成熟武器化代码**（14 个重点编号中仅 `CVE-2026-103355` 检得 1 个只读验证型仓库）。跨期 KEV 方面，NetScaler 旧条目（`CVE-2026-88771`/`88772`）已逾期 5 天，与本期新增条目叠加，Citrix 边界网关闭环压力显著。**本站无内部资产台账，本地资产关联情况均标注“不适用/待核查”，需各资产归属单位自行核查。**

### 3.1 CVE-2026-88779 — Citrix NetScaler ADC / NetScaler Gateway 内存缓冲区越界（已在野利用）

!!! danger "高危漏洞（已被 CISA KEV 收录，确认在野利用）"
    Citrix NetScaler ADC 与 NetScaler Gateway 存在内存缓冲区越界缺陷，未经认证的网络攻击者可通过构造请求触发越界，导致服务崩溃（拒绝服务）或潜在的代码执行。

#### 3.1.2 漏洞摘要

该漏洞影响 Citrix NetScaler ADC 与 NetScaler Gateway 的请求处理路径。漏洞成因在于对内存缓冲区边界限制不当，攻击者可通过网络发送精心构造的请求触发越界内存操作。根据 NVD/CISA-ADP 的评分向量，该漏洞**无需认证、无需用户交互、网络可达即可触发**，主要影响可用性（`VA:H`），可导致设备进程崩溃或服务不可用，并存在升级为代码执行的潜在风险。

Citrix 已于 2026-09-27 前后针对 NetScaler 系列发布多编号修复，并在官方支持文章（CTX697174）与本条公告中确认**已观测到针对未部署缓解措施环境的攻击活动**；CISA 于 **2026-10-04** 将该编号纳入已知被利用漏洞（KEV）目录，联邦机构整改期限为 **2026-10-07**。NetScaler ADC/Gateway 广泛部署为 VPN 网关与安全远程访问入口，一旦被利用将直接影响企业内网边界。

#### 3.3.2 漏洞摘要

该漏洞位于 InternLM MindSearch（一个基于大模型的搜索智能体框架）的 `mindsearch/agent/graph.py` 中 `ExecutionAction.run` 函数。组件“规划器代理（Planner Agent）”在处理 `inputs` 参数时未做充分校验，攻击者可通过构造输入使系统执行注入的代码。漏洞**可远程触发**，披露材料称“已公开披露给公众、可能被使用”，且**厂商被提前联系但未作任何回应**，因此当前无官方补丁。

MindSearch 通常部署为联网的智能体服务，若暴露于公网，攻击者可在服务进程权限下执行代码。

#### 3.3.5 利用条件与技术原理

**技术原理：**

规划器代理在执行动作时，将用户可控的 `inputs` 直接传入代码执行路径，缺少沙箱与输入校验，导致代码注入。攻击者可借此在服务进程中执行任意代码。

**核心利用链：**

```text
攻击者
  └─ 向 MindSearch 服务提交特制请求
      └─ 污染 Planner Agent 的 inputs
          └─ ExecutionAction.run 未校验即执行
              └─ 以服务进程权限执行任意代码
```
