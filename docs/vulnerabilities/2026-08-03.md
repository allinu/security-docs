#### 3.1.2 漏洞摘要

该漏洞存在于 Thermo Fisher Scientific Applied Biosystems 基因分析仪与人类识别（HID）软件生成的 `.fsa` / `.hid` 输出文件中：文件缺少完整性（数字签名）校验，攻击者可在分析软件加载数据前修改这些文件，且几乎无法被察觉，从而篡改 DNA 检测数据、导致不准确的检测结果。公开演示表明可合并两份样本的数据，直接影响法医 DNA 证据（刑事案件"金标准"证据链）的可信度与临床检测准确性。

> 该漏洞由 Nathan Adams（Forensic Bioinformatics）、Kevin Dyer、Laura Gaydosh Combs 发现，并经 CISA 协调披露。测试中首次成功篡改文件用时约 45 分钟（AI 辅助完成），说明利用门槛较低。

#### 3.1.5 利用条件与技术原理

| 条件 | 状态 | 说明 |
| --- | --- | --- |
| 网络可达 | 是 | 需可访问实验室网络、存储系统或外部数据传输链路 |
| 身份认证 | 无需 | 对数据文件本身无认证要求（需取得文件访问途径） |
| 用户交互 | 需要 | 分析软件需加载被篡改的 `.fsa/.hid` 文件 |
| 特定配置 | 是 | 依赖未启用数字签名校验的旧版软件 |
| 利用复杂度 | 低 | 修改文件本身简单，且几乎不可被察觉 |

**技术原理：**

`.fsa/.hid` 输出文件生成后不包含数字签名或等效完整性校验，分析软件加载时也不验证文件是否被改动。攻击者修改文件中的检测数据（如合并样本数据）后，软件照常输出"合法"分析结果，缺乏可追溯的完整性证据。

**核心利用链：**

```text
攻击者
  └─ 获得实验室网络/存储/数据传输链路的访问能力
      └─ 定位并复制 .fsa/.hid 输出文件
          └─ 修改文件中的 DNA 检测数据（可合并两份样本）
              └─ 放回原位置（无签名校验，改动不被察觉）
                  └─ 分析软件加载被篡改数据 → 输出失真检测结果
```

#### 3.1.11 风险影响

漏洞成功利用后，可能导致：

- 篡改 DNA 检测数据，导致检测结果失真；
- 法医证据链（刑事案件证据）可信度受损；
- 临床检测误判，影响患者诊疗决策；
- 在无法检测的情况下破坏数据完整性（近无痕篡改）。

#### 3.2.5 利用条件与技术原理

| 条件 | 状态 | 说明 |
| --- | --- | --- |
| 网络可达 | 是 | 需可达使用 pgsql 扩展 / BCMath 的 Web 应用或服务 |

**技术原理：**

- 17543：ext-pgsql 在转义反斜杠时处理不当，攻击者可在参数中构造反斜杠逃逸 `E'...'` 字符串字面量边界，注入额外 SQL 语句；
- 17544：`bccomp()` 在特定操作数组合与 scale 参数下发生越界写，破坏栈与堆内存。

**核心利用链：**

```text
攻击者
  └─ 发现公网/内网中调用 ext-pgsql 或 bccomp() 的 PHP 应用
      └─ 构造恶意参数（反斜杠逃逸 / 畸形操作数）
          └─ 触发 PHP 运行时缺陷（转义不当 / 越界写）
              └─ 实现 SQL 注入或内存损坏
                  └─ 潜在数据窃取 / 服务进程上下文代码执行
```

#### 3.3.5 利用条件与技术原理

| 条件 | 状态 | 说明 |
| --- | --- | --- |
| 网络可达 | 部分 | 64530 需 RED qdisc + act_ct 配置且可发送乱序分片；其余多为本地触发 |
| 身份认证 | 本地用户 | 本地提权类漏洞需普通用户权限；KVM 类需客户机内低权限用户 |
| 用户交互 | 不需要 | — |
| 特定配置 | 是 | 64530 依赖 qdisc/连接跟踪特定配置；KVM 类依赖虚拟化场景 |
| 利用复杂度 | 中 | 内核利用通常需绕过内核缓解机制 |

**技术原理：**

- **CVE-2026-64530**：`tcf_classify()` 可返回 `TC_ACT_CONSUMED` 而 skb 仍由分片重组引擎（如 act_ct 处理乱序分片）持有，`tcf_qevent_handle()` 未处理该返回值，调用方继续操作不再属于自身的 skb，造成 UAF；
- **CVE-2026-52993**：`tipc_msg_validate()` 可能重分配正在校验的 skb 并释放旧对象，`tipc_buf_append()` 错误路径对已释放指针再次释放（双重释放）；
- **CVE-2025-10263**：Arm 处理器广播 TLBI 在执行内存权限变更时存在时序缺陷，可能先于受影响内存访问完成全局可见，允许非授权写入更高异常级资源（提权）；
- **KVM 系列（46113/53359/63807）**：shadow MMU 因异常 GFN/role 出现 UAF、大页映射校验缺失导致越界读，客户机内低权限用户可破坏宿主机内核内存。

**核心利用链：**

```text
攻击者
  └─ 获取本地普通用户权限（或客户机内低权限用户）
      └─ 触发特定子系统（TIPC/KVM/qdisc/isofs/xfrm/ipc）
          └─ 构造恶意输入触发内存管理缺陷（UAF/双重释放/越界）
              └─ 绕过内核缓解机制
                  └─ 实现权限提升至 root / 信息泄露 / 拒绝服务
```
