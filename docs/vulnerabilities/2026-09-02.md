### 1.3 今日重点关注

1. **Gen Digital Avast 杀毒软件零日权限提升（PoC「PrettyPrague」已公开，暂无 CVE）**  
   攻击者可利用 Avast Sandbox 组件缺陷转储 Windows SAM 数据库并获取 SYSTEM Shell；研究者声称 PoC 兼容任意 Avast 版本，且在全补丁 Avast + Windows 11 25H2 上有效，并推测 AVG、Norton 等 Gen Digital 产品同样受影响。建议关注官方修复进展，并对终端提权行为与 SAM 访问加强监控。

2. **Kaspersky Endpoint Security 零日权限提升（PoC「HardBreacher」已公开，暂无 CVE）**  
   PoC 利用 Kaspersky Endpoint Security（v14.0.0.504 验证环境）的提权缺陷，成功后可在 System32 释放当前用户完全权限的 DLL（`MY_SNAKE_IS_SOLID.dll`），并可控制杀软 UI 进程致其失效。Kaspersky 声称已修复，建议核实终端实际安装版本与修复有效性。

3. **PaperCut `CVE-2026-81578`/`CVE-2026-82078` 被 CISA 纳入 KEV（修复截止 09-14）**  
   CISA 确认两漏洞正被在野利用，Huntress 在两家客户环境发现利用痕迹并完整复现预认证 RCE 链（观察活动以系统发现为主）；安全圈公众号报道国内攻击者已开始链式利用。未安装 Emergency Patch Release 2 的 PaperCut 实例须立即修复。

### 1.4 综合研判

本期窗口内两枚新增漏洞呈现同一风险画像：**安全软件自身的本地权限提升零日 + PoC 已公开（暂无 CVE、暂无官方补丁确认）**。杀毒/终端防护软件是多数企业防御体系的地基，此类零日一旦被攻击链利用，可直接击穿 EDR/AV 检测并窃取本机凭据（SAM），且研究者 Chaotic Eclipse 历史发布的同类零日（Undefend、RedSun Defender 等）**多次被随后发现在野利用**，需警惕 PrettyPrague/HardBreacher 的武器化扩散。叠加 CISA 已将 PaperCut 两漏洞纳入 KEV（在野利用确认、09-14 前须修复完毕）及针对 Langflow/Rails 等组件的批量凭证刺探活动，今日整体威胁等级上调为"重要"。

!!! danger "研判结论：较高风险"
    今日最主要风险点为两大安全软件零日提权 PoC 公开（Avast「PrettyPrague」、Kaspersky「HardBreacher」，暂无 CVE、暂无确认补丁，安全软件被击穿将导致防御体系失效，建议按 P1 加强终端监控并跟踪厂商修复）与 PaperCut `CVE-2026-81578`/`CVE-2026-82078` KEV 在野利用跟进（09-14 前完成 Emergency Patch Release 2 安装）。建议终端侧重点监控提权行为、SAM 访问异常与 System32 目录新增 DLL，服务侧优先处置仍暴露公网的 PaperCut 实例。

### 3.1 暂无 CVE（PoC：PrettyPrague）— Gen Digital Avast 杀毒软件零日权限提升漏洞

!!! danger "高危漏洞"

#### 3.1.2 漏洞摘要

该漏洞存在于 Gen Digital（原 Avast）Avast Antivirus 的沙箱（Avast Sandbox）组件中。安全研究员 Chaotic Eclipse（又名 INFINITE NIGHTMARE、MSNightmare、Nightmare-Eclipse，以公开安全软件零日 PoC 著称，此前曾发布针对 Microsoft Defender 的 Undefend、RedSun 等零日）于 08-30 在 GitHub 公开代号为 **PrettyPrague** 的 PoC 利用程序。

研究者声称：PoC 通过滥用 Avast Sandbox 中的缺陷，可从沙箱环境逃逸并以高权限访问宿主系统资源，转储 Windows **SAM** 数据库并生成一个 **SYSTEM 权限的 Shell**；PoC 在**全补丁的 Avast Antivirus + Windows 11 25H2** 上验证有效，且兼容任意版本 Avast。研究者还推测该缺陷可能影响 Gen Digital 旗下其他产品（如 AVG、Norton），但该推测尚未被证实。具体漏洞机制与技术细节未公开披露。

> 该漏洞的威胁重点在于：杀毒软件是终端防御的最后一环，其自身被提权击穿后，攻击者可窃取系统凭据（SAM）并关闭/绕过本机安全检测，为横向移动与持久化铺路；且发布者历史零日（Undefend 等）曾被发现在野利用，武器化风险需提前防范。

**技术原理：**

具体缺陷机制未公开。根据研究者披露信息，漏洞位于 Avast Sandbox（沙箱隔离组件）：沙箱内进程的权限边界/资源隔离存在缺陷，攻击者可通过构造特定操作绕过沙箱限制，以更高权限访问宿主系统资源（包括注册表 SAM 配置单元），从而转储本地账户哈希并派生 SYSTEM Shell。研究者未公布触发细节与补丁规避细节。

**核心利用链：**

```text
攻击者（本地低权限）
  └─ 获得初始立足点（钓鱼/漏洞/供应链等，需本地代码执行）
      └─ 运行 PrettyPrague PoC（C 源码编译）
          └─ 利用 Avast Sandbox 权限边界缺陷
              └─ 以高权限访问宿主系统资源
                  └─ 转储 SAM 数据库（本地账户凭据）
                      └─ 派生 SYSTEM 权限 Shell
                          └─ 关闭/绕过杀软检测，横向移动或持久化
```

#### 3.2.11 风险影响

漏洞成功利用后，可能导致：

- 在 System32 目录植入当前用户完全权限的 DLL，实现提权并留下可疑文件；
- 控制 Kaspersky 杀软进程，致其停止工作或错误授予/阻断文件访问，防护失效；
- 以提升后的权限窃取凭据、安装持久化、开展横向移动；
- 安全软件被击穿后，恶意行为（勒索、挖矿、窃密）可绕过检测长期驻留。
