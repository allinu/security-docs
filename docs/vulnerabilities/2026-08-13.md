### 1.3 今日重点关注

1. **`CVE-2026-62878`：Windows DNS Server 栈缓冲区溢出远程代码执行漏洞（可蠕虫化，CVSS 9.8）**  
   未认证远程攻击者向受影响 DNS 服务发送特制报文即可触发栈溢出并执行代码，无需用户交互、无需认证，且被微软与安全社区评估为**可蠕虫化（wormable）**。互联网暴露的 DNS 服务器为主要风险面。当前状态为 **补丁已发布（2026-08-11 补丁日）**、**公开 PoC 未发现**、**在野利用未确认**，建议对公网 DNS 服务器立即升级并收敛暴露面。

2. **`CVE-2026-68820`：Windows afd.sys（WinSock 内核驱动）释放后使用本地提权漏洞（在野利用，已入 KEV）**  
   已获本地低权限（通过身份验证）的攻击者可利用 afd.sys 中的 use-after-free 竞争条件，以 SYSTEM 权限执行代码，无需用户交互。微软**确认已在野利用**，CISA 于 2026-08-11 收录进 KEV。当前状态为 **补丁已发布**、**公开 PoC 未发现**，建议立即排查并升级。

3. **`CVE-2026-50656`：Microsoft Defender 引擎提权漏洞（"RoguePlanet"）补丁被 "ShieldBreak" 完整绕过**  
   Microsoft Malware Protection Engine（mpengine.dll）存在竞争条件导致的本地提权漏洞（CVSS 7.8，2026 年 7 月初已打补丁）；研究者 Chaotic Eclipse 于 2026-08-12 发布 **ShieldBreak PoC**（GitHub 407 stars），宣称 100% 成功率完整绕过官方补丁，可在 Windows 11 25H2 与 Windows Server 2025 上获取 SYSTEM 权限（Windows 10 同样受影响）。当前状态为 **公开可利用代码**、**官方新修复尚未发布**，处置以缓解与监控为主。

4. **`CVE-2026-20349`：Cisco ASA/FTD Remote Access SSL VPN 未认证拒绝服务漏洞（正在被广泛利用，已入 KEV）**  
   未认证远程攻击者向启用 SSL VPN / IKEv2 Remote Access VPN / ZTNA 配置的 Cisco Secure Firewall ASA/FTD 设备发送特制 HTTP 请求，可致设备意外重载（DoS）。CISA 与 HKCERT 均确认**正在被广泛利用**，且**无绕过措施**。当前状态为 **Hotfix 已发布**、**公开 PoC 未发现**，建议对暴露的 VPN 设备立即安装热修复。

5. **`CVE-2026-72898`：Metabase `/api/session/reset_password` SQL 注入漏洞（CVSS 10.0，在野利用，已入 KEV）**  
   Metabase 开源数据分析平台的密码重置数据库端点存在 SQL 注入，未认证远程攻击者可注入任意 SQL 并**获取实例管理员访问权限**（可进一步访问已连接的数据源），CVSS 评分 10.0。CISA 于 2026-08-11 收录进 KEV（在野利用）。当前状态为 **补丁已发布（x.58.24 / x.59.21 / x.60.17 / x.61.11 / x.62.9 / x.63.5）**、**公开 PoC 未发现**。

### 1.4 综合研判

本期为补丁日叠加多重在野利用的高风险窗口：**微软 8 月补丁日修复 398 个漏洞，其中 `CVE-2026-62878`（Windows DNS）无需认证且可蠕虫化，面向公网的 DNS 服务器若不及时升级极易被武器化利用**；**`CVE-2026-68820`、`CVE-2026-20349`、`CVE-2026-72898` 三个漏洞均已被 CISA 确认在野利用并收录 KEV（其中 Cisco VPN 与 Metabase 均为互联网可达服务）**；**`CVE-2026-50656` 的官方补丁被公开 PoC（ShieldBreak）完整绕过，Defender 作为全 Windows 默认防护组件，其绕过意味着攻击者可关停/规避终端防护后实施提权**。微软官方补丁均已发布，处置关键在于**补丁日 72 小时内完成关键资产升级**，对暂无法升级的系统立即实施访问收敛与缓解措施。

#### 3.1.2 漏洞摘要

该漏洞存在于 Windows Server 的 DNS Server 角色中。攻击者无需任何身份认证或用户交互，仅需向受影响服务发送特制构造的网络报文，即可触发栈缓冲区溢出并在目标系统上执行代码。

由于 DNS 服务在域内与互联网环境中普遍部署且默认面向网络开放，微软与安全社区（Security Affairs 等）均将该漏洞评估为**可蠕虫化（wormable）**——一旦公开利用技术出现，可能像历史上的 DNS 蠕虫一样在未打补丁的服务器之间自动传播，因此补丁优先级极高。

#### 3.1.5 利用条件与技术原理

| 条件 | 状态 | 说明 |
| --- | --- | --- |
| 网络可达 | 是 | DNS 服务端口（TCP/UDP 53） |
| 身份认证 | 无需 | 未认证远程利用 |
| 用户交互 | 不需要 | 无点击、无文件打开 |
| 特定配置 | 是 | 需启用 DNS Server 角色 |
| 利用复杂度 | 低 | 构造特制 DNS 报文即可 |

**技术原理：**

DNS Server 服务在解析特制报文（涉及特定记录类型/字段处理路径）时缺乏正确的边界检查，攻击者可控数据被复制到栈缓冲区并越界写入，覆盖返回地址等关键栈数据，进而劫持执行流。NVD 将其归类为 CWE-121 栈缓冲区溢出。

**核心利用链：**

```text
攻击者
  └─ 发现暴露的 DNS Server（TCP/UDP 53）
      └─ 构造恶意 DNS 报文（超长/畸形记录字段）
          └─ 触发 DNS 解析组件栈拷贝越界写
              └─ 覆盖栈返回地址 / 执行流劫持
                  └─ 以 DNS 服务权限执行任意代码
                      └─ 可横向传播（蠕虫化风险）
```

### 3.2 CVE-2026-68820 — Windows afd.sys（WinSock 内核驱动）释放后使用本地提权漏洞（在野利用）

!!! danger "高危漏洞（在野利用）"

#### 3.2.2 漏洞摘要

该漏洞存在于 Windows Ancillary Function Driver for WinSock（afd.sys）——支撑 Windows 套接字 API 的内核态驱动。攻击者需先获得本地低权限（通过身份验证的账号），随后通过运行特制应用程序触发 afd.sys 中的释放后使用（use-after-free）竞争条件，成功后可获取 SYSTEM 权限，整个过程无需用户交互。

微软在 2026 年 8 月补丁日公告中明确该漏洞**正在被积极利用（actively exploited）**，但其 CVSS 利用成熟度标注为 "Unproven"。HKCERT 在 2026-08-12 通告中亦标注该漏洞**正在被广泛利用**并将整体风险评定为高度风险。由于本地提权漏洞常被勒索软件、APT 与蠕虫用于权限提升阶段，且已确认在野利用，处置优先级极高。

#### 3.2.5 利用条件与技术原理

| 条件 | 状态 | 说明 |
| --- | --- | --- |
| 网络可达 | 否 | 本地利用 |
| 身份认证 | 普通用户 | 需通过身份验证的本地账号 |
| 用户交互 | 不需要 | 运行特制应用程序即可 |
| 特定配置 | 否 | 无特殊配置要求 |
| 利用复杂度 | 高 | 需赢得竞争条件（AC:H） |

**技术原理：**

afd.sys 在套接字相关对象（如 IRP/异步完成处理）的生命周期管理上存在缺陷：对象在释放后仍被引用（use-after-free）。攻击者通过精心编排的套接字操作序列制造竞争条件窗口，使已释放内存被重新分配并受控，进而实现内核态任意读写，最终以 SYSTEM 权限执行代码。

**核心利用链：**

```text
攻击者（本地低权限账号）
  └─ 运行特制应用程序
      └─ 触发 afd.sys 套接字对象释放后使用（竞争条件）
          └─ 控制已释放内核对象（堆喷/占位）
              └─ 内核态任意读写原语
                  └─ 提权至 SYSTEM 执行代码
```

时间线：2026 年 6 月中旬微软确认该零日并开始开发补丁；2026 年 7 月初发布安全更新（RoguePlanet 修复）。研究者 Chaotic Eclipse（又名 INFINITE NIGHTMARE / MSNightmare / Nightmare-Eclipse）随后发布补丁绕过 PoC **ShieldBreak**（2026-08-12），宣称**100% 成功率完整绕过 CVE-2026-50656 官方补丁**，在 Windows 11 25H2（含 Canary 通道）与 Windows Server 2025 上验证通过；Windows 10 及对应服务器版本同样受影响（PoC 暂不支持）。研究者还指出特定条件下 Defender 可能额外泄露 8 字节内存数据。该研究者此前已披露 Defender 相关 3 个漏洞及 YellowKey（BitLocker 绕过）、GreenPlasma（CTFMON 提权）等 Windows 零日，其 PoC 可信度较高。

#### 3.4.2 漏洞摘要

### 3.5 CVE-2026-72898 — Metabase `/api/session/reset_password` SQL 注入漏洞（CVSS 10.0，在野利用）

!!! danger "严重漏洞（在野利用）"

#### 3.5.2 漏洞摘要

Metabase 是一款开源的数据分析与可视化平台，可连接多种数据源进行查询与可视化，广泛部署于企业内部。该漏洞位于 `/api/session/reset_password`（密码重置）数据库端点：由于对输入未进行充分的参数化处理，未认证远程攻击者可注入任意 SQL，进而**获取连接实例的管理员访问权限**（admin access），并可能进一步访问 Metabase 已连接的数据源（数据库凭据与数据）。

NVD 评分为 **10.0（Critical）**，CISA 于 2026-08-11 将其收录 KEV（在野利用）。阿里云漏洞库（AVD-2026-72898）亦于 2026 年 8 月收录披露。Metabase 官方建议立即升级至所在版本线的最新补丁版，并**在升级后清除所有活动会话（core_session 表）、核查 API 密钥与管理员账号、轮换数据源凭据**。临时缓解可阻断 `/api/session/reset_password` 端点访问。

#### 3.5.5 利用条件与技术原理

| 条件 | 状态 | 说明 |
| --- | --- | --- |
| 网络可达 | 是 | Metabase Web 服务（默认 3000 端口，常经反向代理暴露） |
| 身份认证 | 无需 | 未认证利用 |
| 用户交互 | 不需要 | 直接构造 HTTP 请求 |
| 特定配置 | 否 | 默认部署即受影响 |
| 利用复杂度 | 低 | 构造注入载荷即可 |

**技术原理：**

`/api/session/reset_password` 端点在拼接待重置账号相关查询时未使用参数化查询，攻击者可通过该端点注入任意 SQL。成功注入后攻击者可操纵应用数据库中的会话/账号数据，直接获取管理员访问权限；由于 Metabase 通常持有多个数据源的连接凭据，风险进一步扩散至下游业务数据库。

**核心利用链：**

```text
攻击者
  └─ 发现暴露的 Metabase 实例
      └─ 向 /api/session/reset_password 构造注入载荷
          └─ 触发未参数化 SQL 查询（CWE-89）
              └─ 篡改会话/账号数据 → 获取管理员权限
                  └─ 访问已连接数据源（凭据与数据泄露）
```
