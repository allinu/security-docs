> 原文摘要（NVD）：The s2Member plugin for WordPress is vulnerable to Remote Code Execution in all versions up to, and including, <= 260927 via the 'item_name' parameter parameter. This is due to insufficient sanitization in strip_php_tags_deep(), which only strips literal '<?' sequences, combined with a post-interpolation placeholder cleanup that reassembles a valid '<?php' opener after the attacker-controlled value has already been embedded in the email template. This makes it possible for authenticated attackers, with custom-level access and above, to execute code on the server.

**核心利用链：**

```text
攻击者
  └─ 定位暴露的 目标组件（目标厂商）
      └─ 构造携带命令/表达式载荷的请求
          └─ 触发 CWE-94 对应处理逻辑
              └─ 以服务进程权限执行任意命令
                  └─ 横向利用或持久化（视环境）
```
