#### 3.1.5 利用条件与技术原理

| 条件 | 状态 | 说明 |
| --- | --- | --- |
| 网络可达 | 是 | 通过网络访问受影响接口或端口即可 |

| 利用复杂度 | 低 | 低——单个请求即可触发 |

**技术原理：**

栈上缓冲区未做长度校验，**超长输入覆盖返回地址**。嵌入式网络设备上常缺少栈保护与 ASLR，单个报文即可劫持控制流；服务以 root 运行时直接等价于设备完全失陷。

**核心利用链：**

```text
攻击者
  └─ 定位暴露的 目标组件（目标厂商）
      └─ 发送特制长度/结构的数据包
          └─ 触发 CWE-119, CWE-121 对应处理逻辑
              └─ 破坏内存并劫持控制流
                  └─ 横向利用或持久化（视环境）
```
