#### 3.1.2 漏洞摘要

Adobe Campaign Classic（ACC）是 Adobe Experience Cloud 的核心组件，也是企业广泛使用的营销自动化平台，承担会员数据管理、邮件/短信营销投放与活动管理等功能，常与 SAP、Salesforce、Oracle 等系统集成，并保存大量客户个人信息（PII）。该漏洞位于其内部管理相关接口：由于对调用者身份与权限的授权校验不完整（CWE-863），未认证请求即可触发任意代码执行路径，攻击者无需持有任何凭据，也无需诱导用户交互。

利用该漏洞的前提是目标实例的管理端点可被网络访问（本地 on-premise 部署受影响）。成功利用后，攻击者可在服务进程（当前用户）上下文中执行任意代码；由于 NVD 评级的 Scope 为 Changed（S:C），影响还可跨越受保护组件边界，波及相邻系统。进一步可读取客户数据与数据库连接配置，具备横向移动与数据外泄风险。厂商披露时未报告在野利用；同批公告还修复了 SQL 注入漏洞 CVE-2026-48448 及 8 个 Adobe Bridge 漏洞。

> 版本背景：7 月公告（CVE-2026-48303，同为 CVSS 10.0 错误授权）的修复版本 build 9397 同样处于本漏洞受影响范围内——即"刚打好补丁的版本"仍需继续升级至 build 9398 及以上。

#### 3.1.5 利用条件与技术原理

| 条件 | 状态 | 说明 |
| --- | --- | --- |
| 网络可达 | 是 | 需可达 ACC Web Console / SOAP 管理端点（常见端口 8443/8080，以实际部署为准） |
| 身份认证 | 无需 | 未认证即可触发 |
| 用户交互 | 不需要 | 无需点击链接或打开文件 |
| 特定配置 | 是 | 需部署 ACC v7 本地实例且管理端点可被网络访问 |
| 利用复杂度 | 低 | 无需凭据与用户交互，构造请求即可触发 |

**技术原理：**

根本原因为错误授权（CWE-863）——ACC 内部管理/执行相关接口对调用者身份与权限的校验不完整，导致未认证请求可直达任意代码执行路径。厂商公告未公开具体端点细节；第三方技术分析（可信度待核实）称攻击面涉及 `/nl/jsp/soaprouter.jsp`（SOAP API 入口）等 JSP 端点。

**核心利用链：**

```text
攻击者
  └─ 发现暴露的 ACC Web Console / SOAP 管理端点（常见 8443 端口）
      └─ 构造未认证的特制请求（SOAP/JSP 调用）
          └─ 绕过管理接口授权校验（CWE-863）
              └─ 以服务进程（当前用户）上下文执行任意代码
                  └─ 读取客户数据与配置凭据，具备横向移动能力
```

> 上述端点为第三方博客技术分析所述（可信度待核实），未经独立验证环境复现；本报告不收录任何利用载荷。

#### 3.1.11 风险影响

漏洞成功利用后，可能导致：

- 未经授权访问系统或业务接口；
- 远程执行任意系统命令（服务进程上下文）；
- 获取应用、系统或数据库权限（ACC 服务账户）；
- 泄露客户 PII、账号、密钥、配置文件及营销业务数据；
- 篡改营销活动配置或业务数据；
- 植入WebShell、后门或恶意程序；
- 横向移动至数据库、邮件服务等相邻系统；
- 中断营销业务服务或破坏系统可用性。

#### 3.1.13 修复与缓解措施

#### 官方修复

1. 将 Adobe Campaign Classic 升级至 `7.4.3 build 9398` 或更高版本（APSB26-114）；2026-08-03 发布的 APSB26-120 提供 build 9399；
2. 安装厂商发布的完整安全补丁（同批修复 CVE-2026-48448 及 8 个 Adobe Bridge 漏洞）；
3. 升级前完成配置、程序和业务数据备份；
4. 在测试环境验证兼容性及回退方案；
5. 升级后核验版本、补丁状态及业务运行情况；
6. 重新执行漏洞检测并留存修复证据。

#### 临时缓解

无法立即升级时，可采取：

- 关闭或禁用受影响组件、接口或功能；
- 将 ACC Web Console / SOAP 管理端点限制在可信网络内，禁止直接暴露于公网；
- 通过防火墙、ACL、安全组仅允许可信IP访问 8443/8080 等管理端口；
- 在WAF、IPS或网关增加对 `/nl/jsp/` 异常请求与路径穿越特征的拦截规则；
- 启用身份认证、多因素认证和最小权限控制；
- 修改默认账号、默认密码及默认密钥；
- 加强日志审计、主机监控和异常外联检测；

### 3.2 CVE-2026-48448 — Adobe Campaign Classic SQL 注入漏洞（CVSS 8.6）

!!! danger "高危漏洞"

#### 3.2.2 漏洞摘要

该漏洞源于 ACC 对 SQL 命令中特殊元素未进行正确中和（CWE-89），攻击者可在未认证条件下通过特制请求注入 SQL 逻辑，导致敏感内存内容泄露，并可进一步利用该能力获得文件系统读取权限（如读取服务器上的配置文件与密钥）。利用该问题不需要用户交互，且 Scope 为 Changed（S:C），影响可跨越受保护组件边界。

该漏洞与 CVE-2026-48449 同批公告发布并一并修复。二者可组合形成"RCE 获取服务账户 Shell → 读取数据库连接配置 → SQLi 读取任意文件 → 横向移动"的数据外泄链（链式利用以各自漏洞成功利用为前提，厂商未披露组合利用案例）。

#### 3.2.5 利用条件与技术原理

| 条件 | 状态 | 说明 |
| --- | --- | --- |
| 网络可达 | 是 | 需可达 ACC 管理/SOAP 端点 |
| 身份认证 | 无需 | 未认证即可触发 |
| 用户交互 | 不需要 | 无需点击链接或打开文件 |

| 利用复杂度 | 低 | 无需凭据与用户交互 |

**技术原理：**

输入校验与参数化查询缺失：ACC 相关接口在拼接 SQL 语句时未对用户可控输入做参数化处理或特殊字符过滤，攻击者通过注入 SQL 特殊元素改变查询语义，触发敏感内存内容泄露，并借助数据库功能扩展为文件系统读取。

**核心利用链：**

```text
攻击者
  └─ 发现暴露的 ACC 管理端点
      └─ 构造含 SQL 注入的未认证请求
          └─ 触发脆弱查询逻辑（CWE-89）
              └─ 泄露敏感内存内容
                  └─ 扩展为文件系统读取（配置、密钥等）
```

## 五、当日处置建议

1. 对已在野利用、已纳入CISA KEV或存在成熟PoC的漏洞立即开展资产排查；
