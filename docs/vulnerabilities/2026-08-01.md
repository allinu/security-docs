### CVE-2026-48449：Adobe Campaign Classic 错误授权漏洞（CVSS 10.0）

| 项目 | 内容 |
|---|---|
| CVE 编号 | [CVE-2026-48449](https://nvd.nist.gov/vuln/detail/CVE-2026-48449) |
| 影响产品/组件 | Adobe Campaign Classic (ACC) v7（Windows / Linux，build 9397 及更早版本受影响） |
| 危害等级 | 严重（CVSS 3.1 = 10.0，`AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H`） |
| 漏洞类型 / CWE | 错误授权（[CWE-863: Incorrect Authorization](https://cwe.mitre.org/data/definitions/863.html)），经 NVD API 核实 |

| ATT&CK | [T1190: Exploit Public-Facing Application](https://attack.mitre.org/techniques/T1190/)（条件性映射：未认证、远程、无需交互的 RCE 特征一致，适用于将 ACC 暴露于公网的部署） |

!!! danger "严重 — CVSS 10.0 满分"
    CVE-2026-48449 为 Adobe Campaign Classic（企业级营销自动化平台）中的**错误授权（Incorrect Authorization）漏洞**。未认证的远程攻击者无需任何用户交互即可在受影响实例上以当前用户上下文执行任意代码，且 Scope 为 Changed（S:C），可影响受保护资源之外的数据与系统。NVD 同时给出 9.8 的次级评分（Scope: Unchanged 场景），两者均为 Critical。

**漏洞描述**（NVD 官方）：Adobe Campaign Classic (ACC) 受一个错误授权漏洞影响，可导致在当前用户上下文中执行任意代码。利用该问题**不需要用户交互**，且 Scope 发生变化（可逃逸至相邻组件）。同批公告还修复了高严重度的 SQL 注入漏洞 CVE-2026-48448 及 8 个 Adobe Bridge 漏洞。

!!! tip "修复建议"
    - 立即升级 Adobe Campaign Classic 至官方修复构建：**7.4.3 build 9399 或更高**（以 [Adobe 安全公告](https://helpx.adobe.com/security/products/campaign/apsb26-114.html) 为准；受影响为 build 9397 及更早版本，[APSB26-120](https://helpx.adobe.com/security/products/campaign/apsb26-120.html) 于 8 月 3 日发布 build 9399）。
    - 若无法立即升级：将 ACC 服务与管理界面限制在可信网络内，**禁止直接暴露于公网**，并加强访问控制与日志审计。
    - 排查 Campaign Classic 服务器日志中是否存在未认证的异常请求与可疑账户操作。

!!! poc "POC / EXP 检索结果"
    未发现公开 POC。GitHub 仓库搜索（关键词 `CVE-2026-48449` 与 `CVE-2026-48449 poc`）均为 **0 结果**；互联网检索未见公开利用代码，Adobe 亦未报告在野利用。如后续出现公开利用代码，本页将更新。

## 其他情报

### 安全事件

- **俄罗斯背景组织劫持酒店/会议 Wi-Fi（行动代号 CaptiveCrunch）** — 微软于 8 月 1 日披露：俄罗斯背景组织 [Storm-2945](https://thehackernews.com/2026/08/hijacked-hotel-wi-fi-pushes-fake.html) 在全球酒店、会议中心等场所劫持公共 Wi-Fi，伪造强制门户登录页与"浏览器更新"提示，向旅客投放 **CornFlake 远控木马（RAT）**，可窃取摄像头画面、麦克风录音与键盘输入，进而劫持企业账户。攻击者在受害者连上 Wi-Fi 的瞬间即完成入侵。防护建议：不在公共 Wi-Fi 上登录企业账户、只通过官方渠道更新软件、使用可信 VPN 与端点防护。

- **CISA 敦促水务行业保护 OT：针对 PLC 的协同攻击** — [CISA 于 7 月 30 日发布警报](https://www.cisa.gov/news-events/alerts/2026/07/30/cisa-urges-water-and-wastewater-systems-sector-protect-ot-against-activity-targeting-plcs)：近期针对水与污水处理系统（WWS）可编程逻辑控制器（PLC）的攻击显著增加，明尼苏达州数十家水务系统的 PLC 遭到入侵，攻击者锁定操作员、迫使系统转人工运行；被入侵的 PLC 管理水质、化学处理与水泵等关键环节。CISA 敦促立即将暴露于互联网的 PLC/OT 设备下线。媒体将攻击关联到伊朗背景组织 [CyberAv3ngers](https://cybernews.com/privacy/cisa-warning-utility-companies-internet-exposed-controls-hack/)。

- **韩国"图片隐写"水坑攻击链：一场持续两年的网络暗战** — [AhnLab 披露 "Operation Double Barrel"](https://securityaffairs.com/196417/apt/south-korea-warns-of-state-backed-watering-hole-attacks.html)：2025 年至 2026 年上半年，15 个韩国正规网站（媒体、医疗机构、教育机构、制造企业）被国家背景攻击者篡改，植入隐藏在图片中的恶意代码，利用韩国金融安全软件（[AnySign4PC](https://thehackernews.com/2026/07/hackers-exploit-anysign4pc-via-hacked.html) 等）漏洞，无需下载提示即在访客系统安装 **SIGNBT / COPPERHEDGE 后门**，并将后门注入合法的 Microsoft 进程以规避检测。访问被篡改网站的普通网民即可能中招。

- **开源清理工具 FluentCleaner 遭假冒官网投毒** — [小众软件报道](https://www.appinn.com/fluentcleaner-fake-website-malware/)：新兴开源 Windows 清理工具 FluentCleaner 走红后即出现假冒官网 **fluentcleaner[.]org** 投放木马。官方唯一来源为 GitHub 仓库 [builtbybel/FluentCleaner](https://github.com/builtbybel/FluentCleaner/releases)（官方发布页已明确警告仿冒站点）。用户下载软件务必核对官方来源与哈希。

- **不止模型漏洞：AI 全链路安全风险（黑鸟）** — 安全研究讨论指出，AI 系统的风险已远超模型层本身：提示注入、工具/插件滥用、记忆投毒、数据外泄与供应链、部署面问题构成全链路攻击面。这与 OWASP 发布的 Agentic Applications Top 10（2026）风险类别（提示注入、工具滥用、数据外泄、记忆投毒、目标劫持、多智能体级联故障）相互印证。AI 安全建设需覆盖模型、工具、数据与运行时全链路。[原文链接](https://mp.weixin.qq.com/s?__biz=MzAxOTM1MDQ1NA==&mid=2451187941&idx=1&sn=14e50c7ccb72001cb7bec161f5377cf9)
